2. Goals, non-goals, constraints

Goal. Read one Apache combined-format log file and print three independent frequency reports — Country, OS, Browser — as percentages of all requests in the file (the brief says “across all 10,000 requests”), sorted descending, two decimal places.

Must

  • Run locally with no web APIs (MaxMind downloadable DB only).
  • Stay correct on the 10k-line sample and remain streaming so larger files do not require loading the whole file into memory.
  • Make adding a fourth dimension (e.g. HTTP status class) a new class + one registration line, not a pipeline rewrite.

Not in v1

  • Live tailing, HTTP service, or dashboard UI.
  • Per-path or time-window reports (easy later via extra dimensions / filters).
  • Distributed processing. 10k–millions of lines is a single process.

4. Assumptions and trade-offs

TopicDecisionWhy / risk
Log format Apache combined (IP, ident, user, time, request, status, size, referer, user-agent). Strict regex first; if it fails, a lenient fallback recovers the IP and a best-effort UA, and the record is marked partial=True. 9,999 of 10,000 lines match the strict regex (§3). The fallback keeps the one truncated line instead of dropping it. A parser interface keeps CLF vs JSON logs swappable.
Denominator Changed in 1.1.0: percentages are over all non-empty lines (10,000 here). A line that cannot be read even leniently still counts, as Unknown in every dimension. The stderr summary reports total / strict / partial / unreadable. The brief says “across all 10,000 requests”, and every dimension's percentages then sum to ~100% over the same base. The old “parsed only” denominator would have silently reported over 9,999.
Country “Other” v1 prints every country. Optional --other-below N rolls remainder into Other to match the sample style. The brief’s sample looks illustrative; the written requirement is “each metric, sorted by frequency”.
Rounding Independent round(pct, 2) (banker's rounding via Python). Do not force a 100.00% sum. Simplest, honest. A largest-remainder pass can be added if a reviewer wants an exact 100.00.
GeoIP misses Private / invalid / unmapped IPs → Unknown. Label = country.names["en"], falling back to registered_country (some anycast / satellite ranges only have that). Never fail the whole run because one IP is unmapped. The DB is from 2026 and the log from 2015, so some drift is accepted.
UA label normalization Take ua-parser's family, then apply a small data-driven alias table (one dict per dimension, not if-chains):
  • OS: Mac OS X → Mac OS; Windows 7/8/XP/Vista… → Windows; Ubuntu, Debian, Fedora… → Linux; Other / empty → Unknown.
  • Browser: Other / empty → Unknown. Real families are kept (Chrome, Firefox, Mobile Safari, Googlebot, IE…).
 ua-parser says Other where the brief says Unknown, and it splits Windows and Linux finer than the sample output does. Never invent Edge from IE. The table can be swapped (e.g. --raw-families) without touching the dimension code.
Bots & feed readers Counted like any other request (~21% of this log). The browser label is whatever ua-parser says (Googlebot, FeedFetcher-Google, …). The brief asks for all requests. Excluding them is a filter decision, not a parsing one, so it lives in an optional RecordFilter, not in the dimensions.
DB distribution Do not commit GeoLite2 (add *.mmdb, GeoLite2-* to .gitignore, which today only has Go patterns). Path via env GEOIP_DB or --geoip. Tests use a tiny fake lookup. Validate at startup that the DB's database_type contains Country or City, and fail fast if someone passes the ASN DB. MaxMind license + binary size. CI must not depend on a secret DB.

6. Architecture

A single-process pipeline. I/O, parsing, dimension extraction, aggregation, and formatting are separate so worktrees can own one box each against shared contracts.

GeoIP lookup. CountryDimension only knows the GeoIpLookup protocol (country_name(ip) → str). The MaxMindGeoIp adapter is the one module that imports geoip2. It opens GeoLite2-Country.mmdb once, memory-mapped, at startup and fails fast if the file is missing or not a Country/City edition. Each lookup returns country.names["en"], falls back to registered_country, and returns Unknown on AddressNotFoundError, a private IP or an invalid IP. A per-IP cache sits in front of it, which saves ~82% of the lookups on this log (1,753 unique IPs / 10,000 lines). UserAgentLookup follows the same pattern for OS and Browser.

The CLI is a thin composition root. It does not contain parsing regexes or percentage math. That keeps review conversations about design, not a 200-line script.

7. Main processing flow

One pass over the file. Dimensions never need a second read. Lookups may cache by IP / UA string because logs repeat clients.

8. Key abstractions and interfaces

Rule: one class per file. Every class, whether Protocol, dataclass, adapter, test fake or test class, lives in its own module named after it in snake_case (LogRecord → log_record.py). __init__.py files only re-export; they define nothing. Module-level constants and helper functions may sit in the file of the one class that uses them. Wave 0 lands the contracts below in src/weblogstats/contracts/, one file each, so every worktree can import them immediately. They are shown together here only for reading.

from dataclasses import dataclass
from datetime import datetime
from typing import Iterator, Protocol

@dataclass(frozen=True)
class LogRecord:
    ip: str
    timestamp: datetime | None
    method: str
    path: str
    protocol: str
    status: int | None
    bytes_sent: int | None
    referer: str
    user_agent: str
    raw: str
    partial: bool = False   # True when produced by the lenient fallback

class LogSource(Protocol):
    def lines(self) -> Iterator[str]: ...

class LogParser(Protocol):
    def parse(self, line: str) -> LogRecord | None: ...

class Dimension(Protocol):
    name: str  # printed heading: "Country", "OS", "Browser"
    def extract(self, record: LogRecord) -> str: ...

class GeoIpLookup(Protocol):
    def country_name(self, ip: str) -> str: ...  # "Unknown" if unmapped

class UserAgentLookup(Protocol):
    def os_family(self, user_agent: str) -> str: ...
    def browser_family(self, user_agent: str) -> str: ...

@dataclass(frozen=True)
class DimensionReport:
    name: str
    rows: tuple[tuple[str, float], ...]  # (label, percent) desc

class Aggregator(Protocol):
    def observe(self, dimension: str, label: str) -> None: ...
    def snapshot(self, other_below: float | None = None) -> list[DimensionReport]: ...

class ReportFormatter(Protocol):
    def format(self, reports: list[DimensionReport]) -> str: ...

@dataclass
class RunStats:             # feeds the stderr summary
    total: int = 0
    strict: int = 0
    partial: int = 0
    unreadable: int = 0

Composition: CountryDimension(geoip), OsDimension(ua), BrowserDimension(ua). The aggregator is dimension-agnostic: it only sees names and labels. That is the extensibility hinge.

9. Extensibility

New dimension (example: Status class) — add dimensions/status_dimension.py containing only class StatusDimension with name = "Status" and extract returning 2xx/4xx/… Register it in the CLI list. No aggregator or formatter change.

New output format — implement ReportFormatter, one file per formatter (formatting/json_report_formatter.py, formatting/csv_report_formatter.py). Choose with --format text|json.

New log dialect — implement LogParser. Keep LogRecord stable; unknown fields can be ignored.

New geo source — implement GeoIpLookup (offline CSV, test fake). Production stays on MaxMind file.

Filters later — optional RecordFilter protocol in front of dimensions (e.g. only GET, only 200, or BotFilter behind --exclude-bots, using ua-parser's device family Spider plus a small regex for feed readers). Not built in v1. Filtered records leave the denominator, and the stderr summary says how many.

10. Output contract

Stdout matches the assignment sample shape. Headings have a trailing colon. One blank line between metric blocks. Labels and percentages separated by a single space. Percentages always two decimals and a % sign.

Country:
United States 35.10%
United Kingdom 27.55%

OS:
Windows 64.36%

Browser:
Chrome 35.45%

Sort: count descending, then label ascending for ties. Labels are the display strings from extractors after alias maps.

11. Errors, Unknown, Other

  • Missing log file / missing MMDB: non-zero exit, clear message. Do not start a partial report.
  • Malformed line: never dropped and never fatal. Strict regex → lenient fallback (partial=True) → if even the IP cannot be read, the pipeline uses an empty LogRecord, so every dimension yields Unknown. The line stays in the denominator. stderr on this log: total=10000 strict=9999 partial=1 unreadable=0.
  • UA "-", bytes -, \x escapes: valid input, not errors (§3).
  • Wrong GeoIP DB type (e.g. ASN): fail at startup with a message naming the expected Country/City edition.
  • Unknown: extractor return value when IP or UA cannot be classified. Always a first-class bucket.
  • Other: only if --other-below is set (percent threshold). Applied per dimension after percentages are computed, then Other is appended last (or sorted if it is large — v1: Other always last to match the sample).

12. Subagent plan: worktrees, branches, PRs

Implementation is done by Claude subagents (model Sonnet, effort high), each in its own git worktree on its own dev/* branch. Every agent works test-first, runs the full suite and lint before it hands back, and finishes by pushing its branch and presenting a PR into master. Nobody merges their own PR: the human reviews and merges. Wave 0 is a short serial bootstrap that publishes contracts and a green empty CLI. Once it is merged, the four Wave 1 branches only add files under their owned paths, so they merge independently.

Each agent's full brief is a file in docs/agents/ on master. The shared rules (TDD loop, one class per file, branch/PR protocol, data paths) are in docs/agents/00-common.md, and every brief starts by reading it.

Order

  1. The human commits and pushes the HLD + briefs to master.
  2. Spawn bootstrap. Review its PR and merge it into master.
  3. Spawn parser, geoip, ua, report in parallel. Each branches from the updated master. Review and merge the 4 PRs in any order (the files are disjoint).
  4. Spawn compose. Review and merge its PR.

Rules for every agent: implement only owned paths; import contracts, never another Wave 1 agent's module; never edit contracts (propose the change in the PR description instead); write the failing test first; the PR is presented only after the full suite and ruff pass, and it includes their output.

13. Testing and verification

TDD is mandatory. For every behaviour: write the test, run it, and see it fail for the right reason (red). Write the minimum code to pass (green), refactor, then commit. Tests sit next to production code in the same commit series. No production class is merged without a test module that exercises it. Before a PR is presented, the agent runs python -m pytest -q (full suite, not just its own tests) and ruff check ., and pastes both outputs into the PR description.

  • Unit: parser, each dimension with fakes, aggregator sort/percent/Other. One test module per production class.
  • Contract: fakes in tests/fakes/ satisfy the Protocols (checked with isinstance on runtime_checkable protocols) so Wave 1 tests and Wave 2 wiring agree.
  • Integration (marked @pytest.mark.data): tests that need data/GeoLite2-Country.mmdb or the 10k log are skipped when the file is absent, so CI and fresh clones stay green.
  • Golden: fixture → exact stdout (Wave 2). Assert that every dimension sums to the same total (= number of non-empty lines).
  • Manual: full 10k file once GeoLite2-Country is on disk. Expect denominator 10000, Unknown OS/Browser ≥ 1.9% (the 190 "-" UAs plus bots), and Windows / Chrome / United States near the top. The brief sample numbers are illustrative and will not match.
  • Browser / UI: this HLD page itself — comments persist in localStorage; copy/clear buttons.

If a reviewer asks “how do you add a dimension?”, the answer is: write the test, add dimensions/status_dimension.py implementing Dimension, register it in the CLI list. The README has the recipe. That sentence is the design’s success criterion.
